# rollpack

Roll identifiers and pack tokens for idempotent workflows.

**Site:** https://theworker02.github.io/rollpack/

## Install / run

```bash
git clone https://github.com/theworker02/rollpack.git
cd rollpack
node src/cli.js
node --test
```
